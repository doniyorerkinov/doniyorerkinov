## 🚀 What I'm building

### [Toolkave](https://toolkave.com) — 131 free tools that never upload your files

A utility site in **Uzbek, Russian and English**, built because the tools people
here need are either in English only, behind a sign-up, or want your documents
on someone else's server.

Every tool runs **entirely in the browser**. PDFs are merged, images are
resized, presentations are built and documents are converted on the visitor's
own device — no file is ever sent anywhere, which is a privacy promise the
architecture keeps rather than the privacy policy.

- **Nuxt 4** on **Cloudflare Workers**, with **D1** for the parts that need state
- 131 tools across 12 categories, each one prerendered in three languages with
  proper `hreflang` and canonicals
- **PDF** work with pdf-lib, **.docx** and **.pptx** read and written as raw
  OOXML, **image** processing on canvas, **video and audio** through
  ffmpeg.wasm, background removal with **ONNX Runtime**
- Two **Telegram bots** ([@Toolkavebot](https://t.me/Toolkavebot),
  [@pdfyasashbot](https://t.me/pdfyasashbot)) sharing one Worker: **600+ users**
  turning photographs into PDFs, with the whole conversation — batching,
  language, counters — running in the same codebase

**Stack:** Nuxt 4 · TypeScript · Pinia · Tailwind v4 · Cloudflare Workers · D1 ·
WebAssembly
